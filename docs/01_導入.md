# 導入

どの PC でも同じ手順で設計を始められる状態にする．所要時間は 5分程度である．

## 1. 必要なもの

| 項目 | 条件 |
| --- | --- |
| OS | Windows |
| SOLIDWORKS | 2024 で動作を確認 |
| Python | 3.10 以上 |
| Microsoft Word | 正式文書の PDF 出力に使用 |
| MISUMI RAPiD Design | ねじ類の取り込みに使用．無くても設計は可能 |

## 2. インストール

```text
git clone https://github.com/waarrk/swkit.git
python -m venv .venv
.venv\Scripts\pip install -e swkit[rapid,doc]
```

`rapid` は RAPiD Design の画面操作に使う pywinauto を，`doc` は正式文書の生成に使う python-docx を追加で入れる．

## 3. 設定

```text
.venv\Scripts\swkit setup
```

`swkit setup` の処理は次の 3つである．

1. 入っている SOLIDWORKS の版とテンプレートを調べ，設定ファイル `%USERPROFILE%\.swkit.json` を作る．
2. 設計者スキル `swkit-designer` を `%USERPROFILE%\.claude\skills\` に入れる．
3. 環境を点検する．

設定ファイルの内容は次のとおりである．テンプレートを空にすると，SOLIDWORKS の既定のテンプレートを使う．

```json
{
  "progid": "SldWorks.Application.32",
  "part_template": "D:/templates/部品.prtdot",
  "asm_template": "D:/templates/アセンブリ.asmdot"
}
```

| 項目 | 意味 | 環境変数での上書き |
| --- | --- | --- |
| progid | 使う SOLIDWORKS の版．32 が 2024 に対応 | SWKIT_PROGID |
| part_template | 部品のテンプレート | SWKIT_PART_TEMPLATE |
| asm_template | アセンブリのテンプレート | SWKIT_ASM_TEMPLATE |

テンプレートは SOLIDWORKS の標準の場所から探す．別の場所に置いている場合は設定ファイルを手で直す．

## 4. 点検

```text
.venv\Scripts\swkit doctor
```

各行が `[OK]` であれば設計を始められる．`[NG]` の行には対処が表示される．

| 点検項目 | NG のときの対処 |
| --- | --- |
| pywin32 | `pip install pywin32` |
| SOLIDWORKS | インストールの確認 |
| 設定ファイル | `swkit setup` の実行 |
| テンプレート | 設定ファイルのパスの修正 |
| MISUMI RAPiD Design | `pip install swkit[rapid]` |
| 設計者スキル | `swkit setup` の実行 |

## 5. 設計者スキル

設計者スキルは，Claude Code が SOLIDWORKS の設計をするときに読む手順書である．設計の進め方，スケッチとフィーチャの決まり，購入品の扱い，文書の作り方を定めている．入れた PC では，同じ決まりで設計が進む．

スキルだけを入れ直す場合は `swkit skill` を実行する．原本は `src/swkit/templates/skill/` にある．
