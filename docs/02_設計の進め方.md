# 設計の進め方

設計値を 1か所に置き，組立モデルから設計する．3次元モデル，計算，部品表，文書はすべて同じ設計値から生成する．

## 1. プロジェクトの作成

```text
swkit new <名前> [場所] [--code 文書番号の先頭]
```

次の構成ができる．フォルダ名は小文字とし，`doc/` の下は番号付きの日本語名とする．

```text
analysis/        設計値 params.py，事前計算，計算結果 out/
cad/             生成した部品とアセンブリ
cad_source/      製造元の配布データ
doc/             文書と記録
  00_管理/         文書管理台帳
  01_計画/         設計開発計画書
  02_要求/         要求仕様書
  03_設計/         詳細設計書，計算書，図
  04_審査/         設計審査記録
  05_検証/         設計検証記録
  06_妥当性確認/   妥当性確認の計画と記録
  07_変更/         設計変更記録
  08_購買/         部品表，見積と在庫の確認記録
  09_提出/         発行した提出物
quote/           見積の取得
src/<名前>/      生成スクリプト build.py
CLAUDE.md        プロジェクトの決まり
```

`doc/` の区分は ISO 9001 の設計・開発の段階に対応する．計画，要求，設計は改訂する文書であり，審査，検証，変更，購買は書き換えない記録である．

## 2. 設計値

設計値は `analysis/params.py` に置く．大文字の名前は SOLIDWORKS のグローバル変数になる．

```python
BASE_L, BASE_W, BASE_T = 120.0, 80.0, 10.0      # [仮] 長さ × 幅 × 板厚
BOLT_X = 20.0                                   # 固定ボルト M5 の位置 ±
```

値の根拠をコメントに書く．`[要求]` は仕様で決まる値，`[図面]` は製造元の図面の値，`[計算]` は事前計算で決めた値，`[仮]` は未確定の値である．

強度や釣合いの事前計算も `analysis/` に置き，同じ `params.py` を読む．

## 3. 生成スクリプト

`src/<名前>/build.py` に `Project` を継承したクラスを書く．書くのは部品の形，ユニットの組立，共締め穴の 3つである．

```python
class Builder(Project):
    def __init__(self, use_cache=True):
        super().__init__(P, CAD, LABELS, use_cache=use_cache)

    def layout(self, top): ...          # トップアセンブリのレイアウトスケッチ

    @cached_part
    def base(self): ...                 # 部品を作って名前を返す

    def base_asm(self, asm): ...        # ユニットに部品を配置する

    def shared_holes(self): ...         # 共締め穴の一覧

    def run(self):
        units = (("台", D_BASE, self.base_asm),)
        self.build(TOP / "製品.SLDASM", units, self.shared_holes(), layout=self.layout)
```

書き方の詳細は [モデルの書き方](03_モデルの書き方.md) に示す．

## 4. 生成の手順

`Project.build` は次の順で進む．手順と速く終わらせる工夫は swkit が持ち，設計ごとのスクリプトには書かない．

1. トップアセンブリとユニットごとのサブアセンブリを先に作る．
2. トップアセンブリにレイアウトスケッチを描く．
3. 部品を作り，各ユニットへ基準平面との合致で配置する．
4. 穴の対象になるユニットをトップアセンブリへ載せる．
5. 共締め穴を組立状態の穴フィーチャとして開け，加工部品へ反映する．
6. 残りのユニットを載せる．
7. 拘束状態，干渉，質量と重心を確認し，画像と STEP を書き出す．

## 5. 出力

| 出力 | 場所 | 内容 |
| --- | --- | --- |
| 部品とアセンブリ | cad/ | SOLIDWORKS の文書 |
| cad_mass.json | analysis/out/ | 配置した部品ごとの質量，体積，重心 |
| cad_interference.json | analysis/out/ | 干渉している部品の対と体積 |
| cad_warnings.json | analysis/out/ | 生成中の警告 |
| build_profile.json | analysis/out/ | 処理の種類ごとの所要時間 |
| 画像 4枚 | doc/03_設計/図/ | 等角，正面，上面，側面 |
| STEP | cad/ | トップアセンブリ |

生成のたびに，警告の有無，未拘束の構成部品，干渉の内訳を確認する．干渉は，ねじのはめ合いや Oリングのつぶし代などの意図した重なりと，それ以外に分けて判断する．

## 6. 変更の方法

恒久的な変更は `params.py` か `build.py` を直して再生成する．`cad/` の文書を SOLIDWORKS で直接直した内容は，再生成で失われる．

設計値を変えたら，事前計算，部品表，文書の数値も更新する．
