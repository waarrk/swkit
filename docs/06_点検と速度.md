# 点検と速度

生成したモデルは機械で点検する．生成の所要時間は処理の種類ごとに計測し，変更の無い部分を使い回して短縮する．

## 1. 部品の点検

```text
python -m swkit.inspect_part <部品.SLDPRT>
```

フィーチャの構成，各スケッチの定義状態，関係式を一覧にする．スケッチがすべて「完全定義」であること，寸法が関係式で設計変数につながっていることを確認する．

## 2. 無駄な平面とスケッチの点検

```text
python -m swkit.audit <フォルダまたは文書>
```

次の 3つを数える．どれも 0 であることを確認する．

| 項目 | 内容 |
| --- | --- |
| 使われていない基準平面 | 既定の 3平面を除き，スケッチ・フィーチャ・合致から参照されていない平面 |
| 空のスケッチ | 線も点も無いスケッチ |
| 使われていないスケッチ | フィーチャに使われておらず，名前も付いていないスケッチ |

名前を付けて残したレイアウトスケッチは数えない．製造元の配布モデルの中にある平面は対象外とする．

## 3. 組立の確認

`Project.build` は生成のたびに次を出力する．

| 確認 | 合格の条件 |
| --- | --- |
| 警告 | 警告のあった文書が無い |
| 拘束 | 全ユニットで未拘束の構成部品が無い |
| 干渉 | 意図した重なり以外が無い |

意図した重なりは，ねじのはめ合い，Oリングのつぶし代，端子の基板への挿入などである．件数と組合せを記録し，設計検証記録の根拠とする．

## 4. 所要時間の計測

生成の最後に，処理の種類ごとの回数と所要時間を表示する．同じ内容を `build_profile.json` に保存する．

```text
処理                             回数        秒    1 回 ms
基準平面                          517    289.2       559
構成部品の挿入                       176    254.0      1443
合致                            528    155.3       294
```

入れ子の処理は内側の時間を外側から引くため，合計は重複しない．

## 5. 使い回し

| 単位 | 条件 | 動作 |
| --- | --- | --- |
| 部品 | `@cached_part` を付けたメソッドのソースと，参照した設計値が前回と同じ | 保存済みの部品ファイルを複写 |
| ユニット | 既製品を配置するだけのユニットで，ソース，設計値，使う部品ファイルが前回と同じ | 保存済みのサブアセンブリを複写 |

控えは `cad/` の隣の `.swkit_cache/` に置く．swkit 本体の形状に関わるソースを変えると，すべて作り直す．`--no-cache` を付けると使い回さない．

部品を作るユニットと，共締め穴の対象を含むユニットは，ユニット単位では使い回さない．穴が後から部品へ反映されるためである．

## 6. 表示

既定では，生成中の画面更新，フィーチャツリーの更新，視点のアニメーションを止める．`SW.SHOW = True` にすると，作る過程を画面で確認できる．所要時間は長くなる．
