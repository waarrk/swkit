# 困ったとき

症状ごとに原因と対処を示す．いずれも実際の設計で発生した事例である．

## 1. 起動と接続

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| SOLIDWORKS に接続できない | COM 名が登録されていない | `swkit setup` で版付きの名前を設定 |
| テンプレートが見つからない | 既定のテンプレートのパスが無効 | 設定ファイルにパスを記入 |
| 取り込みで止まる | テンプレートの選択画面が出ている | 有効なテンプレートを設定．swkit は既定のテンプレートを使う設定で読み込む |
| 動作が不安定 | スクリプトを 2本同時に実行 | 1本ずつ実行 |

## 2. スケッチと関係式

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 「スケッチが完全定義でない」 | 位置を決める式が不足 | 頂点の位置を式で与える．斜辺の端点も含める |
| 「関係式を追加できない」 | 対象の文書が前面に無い | swkit が前面にして再試行する．続く場合は文書を閉じて再実行 |
| 「寸法値が式と合わない」 | フィーチャの寸法が別の量 | 対象の寸法がその式の量かを確認 |
| 原点への寸法が付かない | 原点の選択方法 | swkit は原点を外部の点として選択する．直接 API を使う場合も同じ方法を使う |

## 3. フィーチャ

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| キリ穴が作れない | 穴ウィザードは全貫通の指定で失敗する | swkit は止まり穴で作ってから全貫通へ変更する．組立の穴は深さを式で指定 |
| フィレットのエッジが見つからない | 指定した点がエッジ上に無い | エッジの中点か端点の座標を式で与える |
| 同じ穴が 2重に入る | 同じ部品ファイルの複数の構成部品が対象 | 共締め穴の対象に `True` を付け，1個目だけにする |
| 板金の板厚が逆側に付く | 輪郭に対する板厚の向き | 配置の位置を板厚分ずらす |

## 4. 組立と購入品

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 配布データの向きが合わない | 回転の順序 | `vendor.align` の回転は Z，Y，X の順で与える |
| 取り込んだ形状の一部が残る | 面のまま入った形状 | swkit は面の形状も一緒に移動する．取り込み後に外形を確認 |
| RAPiD Design が「SOLIDWORKS を起動してから実行」と表示 | 自動で起動した SOLIDWORKS を認識しない | SOLIDWORKS を通常の方法で起動し直す |
| RAPiD Design の取り込みが検索結果の画面へ進む | 候補の表示前に確定した | swkit は待ち時間を延ばして再試行する．チュートリアルの窓が重なっている場合は閉じる |
| 型番が違うと表示 | RAPiD Design の表記と不一致 | 表示された型番の表記で指定 |

## 5. 文書

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 「文書番号が台帳に無い」 | 未登録 | 文書管理台帳へ番号と名称を登録 |
| 「名称が台帳と違う」 | 原稿と台帳の不一致 | どちらかを修正 |
| 目次のページ番号が空 | Word 以外で PDF を作成 | `swkit.docgen` で PDF まで生成 |
| 「参照先が無い」 | `@fig:名前` などの名前の誤り | 図・表・式の `{#...}` の名前と揃える |

## 6. フォルダの操作

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| フォルダの名前を変えられない | SOLIDWORKS の作業フォルダがその下にある | 文書を閉じ，作業フォルダを別の場所へ移す |
| 部品ファイルを消せない | SOLIDWORKS で開いている | 文書を閉じてから消す |
