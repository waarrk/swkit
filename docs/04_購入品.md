# 購入品

購入品は外形の代用モデルでなく，製造元の形状データを使う．ねじの頭やナットを作図しないと，干渉を見落とす．

## 1. 入手の方法

| 対象 | 方法 | 使う機能 |
| --- | --- | --- |
| 製造元が 3次元データを配布している部品 | STEP，IGES，SLDPRT を取り込み，原点と向きを揃える | `Project.vendor` |
| MISUMI の規格品 | RAPiD Design から型番を指定して取り込む | `swkit.rapid` |
| 取り込み済みの部品ファイル | 作り直さずに登録する | `Project.existing` |
| データが無い部品 | 寸法図から作図し，その旨をプロパティに書く | `Project.finish` |

取り込み元のファイルは `cad_source/vendor/` に置き，入手元を記録する．

## 2. 配布データの取り込み

配布データは原点も向きも部品ごとに異なる．`Project.vendor` は，読み込んだ形状を指定した原点と向きへ移してから保存する．

```python
thr = self.vendor(SRC / "U2_Mini.igs", STD / "ApisQueen_U2-Mini.SLDPRT",
                  rows=..., origin=(177.185, -0.84, -18.28), mat=P.THRUSTER_MAT, mass=0.21, axis=True)
```

`rows` と `origin` は，配布データの座標系で見た，揃えた後の軸の向きと原点である．`mass` を与えると，見かけの密度で質量を合わせる．`axis=True` は X軸に基準軸を作る．

取り込んだ後は，外形の寸法を製造元の図面と比較する．面のまま入った形状も一緒に移動する．

## 3. MISUMI RAPiD Design

```text
python -m swkit.rapid <保存先フォルダ> <型番> [<型番> ...]
```

型番ごとに `MISUMI_<型番>.SLDPRT` を保存し，型番，品名，単価，出荷日を `MISUMI_parts.csv` に記録する．保存先に同じ型番があれば取り込まない．

RAPiD Design には公開された API が無いため，画面を操作して取り込む．前提は次の 3つである．

1. SOLIDWORKS を通常の方法で起動してある．スクリプトから自動で起動した SOLIDWORKS は RAPiD Design から認識されない．
2. SOLIDWORKS の「ツール」から RAPiD Design を起動し，ログインしてある．ログインは人が行う．
3. 実行中は RAPiD Design の窓を前面に置く．他の窓が前面にある間は操作を送らずに中止する．

型番は RAPiD Design の表記に合わせる．長さを指定する型番は小数 1桁まで書く場合がある．例は `VSLSBG8-40.0-M4-N4` である．

取り込んだモデルの原点と向きは品目ごとに決まっている．六角穴付ボルトは座面が原点で，ねじ部が +X へ伸びる．

## 4. 既存の部品の登録

取り込み済みの部品は `Project.existing` で登録し，`place` で配置する．

```python
bolt = self.existing(STD / "MISUMI_SCB5-35.SLDPRT", rho=P.SUS304.rho)
self.place(asm, bolt, X_DOWN, ("BOLT_X", "PLATE_TOP", 0), unit="締結部品")
```

`rho` は密度である．配布モデルに材料が設定されていない場合に与える．設定は 1回だけ行い，以後はファイルを書き換えない．

## 5. 在庫の確認

購入品は価格だけでなく，購入できる状態かを販売元のページで確認する．確認日と結果を部品表に書く．在庫切れの品目は，代替品と合わせて報告する．

RAPiD Design から取り込んだ部品は，単価と出荷日がモデルのプロパティに入っている．

## 6. 加工品の見積りと，作れるかどうかの確認

加工品は meviy に入れて，作れるかどうかと単価，出荷日を確かめる．`pip install swkit[quote]` で Playwright を入れ，インストール済みの Chrome を使う．

| 目的 | コマンド |
| --- | --- |
| ログイン | `python -m swkit.meviy login`．ブラウザが開くので，人がログインする |
| アップロード | `python -m swkit.meviy upload <フォルダ名> <計画.csv>` |
| 見積りの読み取り | `python -m swkit.meviy quote <フォルダ名> <計画.csv> [部品名 ...]` |
| 注意事項の読み取り | `python -m swkit.meviy cautions <フォルダ名> <計画.csv> <部品名>` |
| 直した部品の確認 | `python -m swkit.meviy check <フォルダ名> <計画.csv> <部品名> <版の名前>` |

計画は CSV で，列は 部品，cad，加工方法，材質の区分，材質，表面処理，備考 である．`cad` は部品ファイルの場所で，CSV からの相対で書く．材質は meviy の画面に出る名前で書く．同じ名前が無ければ，前方一致のうちいちばん短い名前を選ぶ．結果は計画と同じ場所の `result/<フォルダ名>/quotes.csv` に入る．

守ることは次の 3つである．

1. 注文しない．行うのは，フォルダの作成，アップロード，見積条件の確定と読み取りまでである．
2. 「この内容で見積依頼へ」は担当者への依頼になるので押さない．
3. ログインは人が行う．ログイン後の状態は，環境変数 `MEVIY_PROFILE` の場所，無ければ `~/.swkit/meviy_profile` に残して使い回す．

### 待ち方

固定の待ち時間は置かず，画面の状態が変わりしだい先へ進む．どこで何秒待ったかを，終了時に表で出す．遅い場所はこの表で探す．

| 段取り | 内容 |
| --- | --- |
| 加工方法 | 一覧で全部品を先に選ぶ．行に加工方法のボタンが出ているあいだは，認識の途中でも押す |
| ビューア | 部品ごとのタブで同時に開く |
| 見積りの計算 | 全部品を先に走らせ，終わった部品から読む |
| 小窓 | 見積り中，対象外，曲げ R の案内，曲げの手順の絵は，内容を記録して閉じる |

### 形を直しながら確かめる

注意事項の説明には，必要な寸法が数字で書かれていることが多い．`requirements` はそこから「どの寸法を，いまの値から，いくつ以上にするか」を抜き出す．`check` は，直した部品を版の名前で入れ直し，見積りとこの一覧を返す．

設計値を直して作り直し，通るまで繰り返す処理は，設計ごとに書く．寸法の名前と設計値の対応は設計ごとに違うためである．繰り返しで直すのは，対応を書いた設計値だけにする．数字の無い注意事項は人が決める．設計値を変えたあとは，全体を作り直して干渉を確かめる．
