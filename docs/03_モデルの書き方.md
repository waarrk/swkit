# モデルの書き方

寸法と位置は数値でなく設計変数の式で書く．式は SOLIDWORKS の関係式として残り，生成後に変数を変えると形が追従する．

## 1. 式

座標と寸法は文字列の式で与える．式には `params.py` の大文字の名前と四則演算を使う．

```python
s.rect("-BASE_L / 2", "BASE_L / 2", "-BASE_W / 2", "BASE_W / 2")
p.extrude_mid("BASE_T", "板 外形切り出し")
```

数値をそのまま書くと関係式が付かず，後から変えられない．

## 2. スケッチ

`p.sketch(base)` で基準平面にスケッチを開く．`base` は `"front"`，`"top"`，`"right"` のいずれかである．座標 (u, v) は平面ごとに次の軸に対応する．

| base | u | v | 平面 |
| --- | --- | --- | --- |
| front | X | Y | 正面 |
| top | X | Z | 平面 |
| right | Z | Y | 右側面 |

| メソッド | 用途 |
| --- | --- |
| `rect(u0, u1, v0, v1)` | 軸に平行な長方形 |
| `poly(pts, close=True)` | 折れ線，多角形 |
| `circle(u, v, d)` | 円 |
| `half_circle(r, upper)` | 原点中心の半円 |
| `arc(p0, p1, r, toward)` | 2点を結ぶ円弧．半径は式につながる |
| `centerline(length)` | 回転体の軸 |
| `convert(pts)` | エンティティ変換．既存のエッジを投影 |
| `offset(segs, d, toward)` | オフセット．線を距離 d だけ平行に移す |

拘束と寸法は自動で付き，スケッチは完全定義になる．符号だけが違う式の対は，中心線への対称拘束と全幅の寸法 1本にまとまる．同じ径の円は等しい値の拘束にまとまる．

円弧の端点は，同じ位置にある線の端点と結合される．`poly` の `free` に頂点の番号を渡すと，その頂点の位置は寸法で決めず，つながる円弧で決まる．板厚一定の曲がり板は，内面の円弧を端点 2つと半径で決め，外面の円弧を `concentric` で同心にする．

```python
inner = s.arc(("-SPAN / 2", 0), ("SPAN / 2", 0), "R + T / 2", toward=(0, "YC"))
s.poly([("-XJ", "T"), ("XJ", "T")], close=False, free=(0, 1))
s.arc(("-XJ", "T"), ("XJ", "T"), "R - T / 2", toward=(0, "YC"), concentric=inner)
```

`toward` は円弧の中心がある側を示す点である．

既存の形状から取れる線は描き直さず，`convert` と `offset` を使う．

```python
edges = s.convert([(0, "H / 2", "T / 2"), ("W / 2", 0, "T / 2")], construction=True)
s.offset(edges, "RIM", toward=(0, 0))
```

`convert` の引数は，投影するエッジが通る点のモデル座標 (x, y, z) である．`offset` の `toward` は，線を移す側を示す点である．

## 3. フィーチャ

1フィーチャを 1加工に対応させる．フィーチャの名前には加工の内容を書く．

| メソッド | 用途 |
| --- | --- |
| `extrude_mid(t, name)` | スケッチ面を中心に両側へ押し出し |
| `revolve(name, cut=False)` | 回転．`cut=True` で回転カット |
| `cut_through(name)` | 全貫通のカット |
| `fillet(pts, r, name)` | フィレット．点を通るエッジを指定 |
| `chamfer(pts, c, name)` | 面取り |
| `hole(base, w, pts, size, name)` | JIS の穴ウィザード |
| `mirror(feats, plane, name)` | ミラー |
| `circular(feats, n, name)` | 円形パターン |
| `linear(feats, pitch, expect_x, name)` | 直線パターン |
| `base_flange(width, t, r, name)` | 板金のベースフランジ |
| `cable(pts, d, name)` | 点列を通るケーブル |

角の丸みはスケッチの円弧でなく `fillet` で付ける．穴は円のカットでなく `hole` で開ける．同じ形の繰り返しは `mirror`，`circular`，`linear` で作る．

```python
p.fillet([(x, 0, z) for x in ("-BASE_L / 2", "BASE_L / 2") for z in ("-BASE_W / 2", "BASE_W / 2")], "BASE_R", "外周 角R")
h = p.hole("right", "-CAP_T", [(0, "PCD / 2")], "M4", "M4 めねじ", from_pos=False, depth="TAP_DEPTH", thread=8)
p.circular([h], 6, "M4 めねじ 等配")
```

`hole` の `size` は，キリ穴なら `"Ø5.5"`，タップ穴なら `"M4"` の形で与える．`w` は穴を開ける面の位置，`from_pos` は工具を入れる向きである．

## 4. 部品の仕上げ

`Project.finish` で材料，色，プロパティを設定して保存する．加工方法と加工基準をプロパティに書くと，部品表に出る．

```python
return self.finish(p, D_BASE / "台板.SLDPRT", P.A5052, 加工方法="板 t10 から輪郭を切り出す",
                   加工基準="前後・左右の中心線")
```

部品を作るメソッドに `@cached_part` を付けると，作り方と設計値が前回と同じ部品は保存済みのファイルを使う．

## 5. 組立

構成部品は固定せず，アセンブリの基準平面に合致で拘束する．

```python
def base_asm(self, asm):
    self.place(asm, self.base(), t=(0, "BASE_T / 2", 0), unit="台")
    self.place(asm, self.block(), t=(0, "BASE_T + BLOCK_H / 2", 0), unit="台")
```

`place` は，部品の 3つの基準平面を，位置の式に対応するアセンブリの基準平面へ一致させる．基準平面は必要に応じて作り，オフセットは式につながる．平面の名前は `LABELS` に「式 → 名前」で与える．

位置ごとの基準平面に意味が無い部品は，`distance=True` を付けて置く．位置が 0 でない方向は基準平面を作らず，既定の平面からの距離合致で拘束する．距離は式につながる．ボルト，スペーサ，コネクタのように数が多い部品に使う．ユニットの基準になる位置は，名前付きの基準平面のままにする．

```python
self.place(asm, bolt, X_DOWN, ("BOLT_X", "PLATE_TOP", "BOLT_Z"), unit="締結部品", distance=True)
```

向きは `rows` で指定する．軸に平行な向きに限る．

| 定数 | 向き |
| --- | --- |
| I3 | そのまま |
| FLIP_X | Y軸まわりに 180° |
| X_TO_Y | 部品の X軸を上へ |
| X_DOWN | 部品の X軸を下へ |
| X_TO_Z | 部品の X軸を Z へ |
| X_TO_NEG_Z | 部品の X軸を −Z へ |

斜めの部品は，レイアウトスケッチに軸の線を描き，`asm.mate` で部品の基準軸をその線へ一致させる．同じ部品の繰り返しは構成部品パターンにする．

| メソッド | 用途 |
| --- | --- |
| `Project.ring_of(asm, name, x, pcd, n, unit, label)` | 中心軸まわりの等配．1個を合致で拘束し，円形パターンで n個 |
| `Project.row_of(asm, name, t, pitch, n, unit, label)` | 軸方向の積層．1個を合致で拘束し，直線パターンで n個 |
| `Project.group_of(asm, items, pitch, n, label, axis)` | 組になった部品の繰り返し．1組を合致で拘束し，直線パターンで n組 |

```python
self.row_of(asm, self.ring(), ("-CORE_L / 2", 0, 0), "PITCH", P.RING_N, u, "リング 積層")
```

ピッチは式につながる．座金，スペーサ，積層した素子に使う．

台と，それに付くねじや端子のように，組になった部品が等ピッチで並ぶ場合は `group_of` を使う．`items` に 1組目の部品を「名前，向き，位置，ユニット名」で並べる．`axis` は並べる方向で，`"x"`，`"y"`，`"z"` のいずれかである．

```python
items = [(holder, I3, ("X0", "Y0", 0), u), (bolt, X_DOWN, ("X0 + BOLT_X", "TOP", 0), u)]
self.group_of(asm, items, "PITCH", 4, "ホルダ 4組", axis="x")
```

アセンブリのツリーには 1組目とパターン 1つが残り，合致と基準平面は 1組ぶんで済む．

## 6. 共締め穴

相手部品と同じ位置にある穴は，部品ごとに開けず，組立状態の穴フィーチャ 1つで開ける．`shared_hole` で宣言すると，`Project.build` がトップアセンブリで開けて各部品へ反映する．

```python
H = self.shared_hole
pts = [(x, 0) for x in ("BOLT_X", "-BOLT_X")]
return [H("top", "BASE_T + BLOCK_H", pts, "Ø5.5", "固定穴 M5", [("台", "ブロック"), ("台", "台板")], "BLOCK_H + BASE_T + 2")]
```

対象は「ユニット名，部品名」の組で指定する．同じ部品ファイルを複数か所で使う場合は 3つ目に `True` を付け，1個目だけを対象にする．深さは必ず式で指定する．
