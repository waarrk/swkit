# CAD モデリング規約

SOLIDWORKS のモデルは swkit（汎用ライブラリ。別リポジトリ waarrk/swkit）を使って、設計ごとのスクリプト（本プロジェクトでは
[src/uwd01/build.py](../src/uwd01/build.py)）が生成する。生成後に人が開いて直せることを前提に、次の規約で作っている。
規約は製品に依らない。手で部品を追加するときも、別の製品を設計するときも同じ規約に従う。

## 1. 寸法の持ち方

| 規約 | 内容 |
| --- | --- |
| 設計値の置き場所 | 設計パラメータのモジュール 1 つ（本プロジェクトでは [ANALYSIS/rov_params.py](../ANALYSIS/rov_params.py)）。事前計算と CAD 生成の両方がここを読む |
| 部品・アセンブリ内の表現 | 同名のグローバル変数（例 `"HULL_ID"`, `"GROOVE_W"`）。寸法は `"D1@ｽｹｯﾁ2" = "GROOVE_POS" + "GROOVE_W"` のような関係式で駆動する |
| 変更の方法 | 恒久的な変更はパラメータを直して再生成する。部品を開いてグローバル変数を変えれば、その部品だけ試せる |

部品間で共通の値は、部品ごとに同名の変数として入っている。SOLIDWORKS 上で 1 つの部品の変数を変えても相手部品は
変わらないので、合わせて変えるか、パラメータから再生成する。

## 2. スケッチ

- すべて完全定義（黒）にする。
- 寸法は部品原点（＝加工基準）から入れる。
- 左右・上下対称の形は、原点を通る中心線（作図線）に対称拘束を掛け、全幅の寸法 1 本で決める。
- 同じ式の位置にある線・点は「同一直線上」「水平／鉛直」拘束でまとめ、寸法は 1 本だけ入れる。
- 同じ径の円・円弧は「等しい」拘束でまとめ、径の寸法は 1 本だけ入れる。
- 回転体の断面は直径寸法で指示する。
- 既存の形状から取れる線は描き直さない。**エンティティ変換**（`Sketch.convert`）で既存のエッジを投影し、
  縁からの一定幅は**オフセット**（`Sketch.offset`）で作る。オフセット距離の寸法 1 本を変数につなぐ。
  元の形状を直せば追従する。

## 3. フィーチャ

フィーチャは加工工程の単位で分け、工程が分かる名前を付ける。

| 形状 | 作り方 |
| --- | --- |
| 角 R | フィレットフィーチャ。半径は変数につなぐ。スケッチに円弧を描かない |
| 面取り | 面取りフィーチャ |
| 穴 | 穴ウィザード（JIS）。キリ穴は JIS ドリルサイズ、ねじは JIS タップ穴。位置スケッチも完全定義 |
| 等配の穴 | 1 穴＋円形パターン |
| 等ピッチの溝 | 1 本＋直線パターン |
| 対称な窓・角穴・ほぞ・穴 | 片側を作ってミラー |
| 曲げのある薄板 | 板金のベースフランジ。開いた輪郭が板の外面で、板厚は曲げの内側に付く。展開図が付く |
| 相手部品と共締めする穴 | トップアセンブリの穴フィーチャで開け、加工部品へ反映する（6 章） |

旋削部品の Oリング溝・シール面の導入テーパは、旋盤の 1 工程で削る形なので回転カットで作る。

## 4. 加工基準

部品の原点と基準平面を、加工基準（または機能上の基準）に置く。カスタムプロパティ「加工方法」「加工基準」に同じ内容を入れる。

| 部品の種類 | 原点・基準 |
| --- | --- |
| 旋削部品（端蓋など） | 基準A: 相手に当たる面、基準B: 中心軸。溝や段の位置は基準A から測る |
| 両端が同じ加工の筒 | 中心軸と長さの中央。片端を作ってミラーする |
| 板からの切り出し品 | 機能上の中心線（相手部品の中心）と板厚中心。板厚は素材のまま |
| 板金 | 取付面（タブの外面）と板の外面 |

## 5. アセンブリ

- アセンブリを先に作る。トップとユニット別サブアセンブリを空で保存してから、部品を作って入れる。
- 構成部品は固定しない。**アセンブリ側に定義した基準平面とレイアウトスケッチに合致で拘束する。**
  - 軸に平行な姿勢の部品: 部品の 3 つの基準平面を、その面が重なる位置のアセンブリ基準平面に一致させる。
    必要な基準平面はアセンブリに作り、オフセットは変数につなぎ、何の面かが分かる名前を付ける。
  - 斜めの部品: アセンブリのレイアウトスケッチに軸の線と中心点を描き、部品の基準軸を線に、基準平面を点に一致させる。
- 等配の購入品は 1 個を合致で拘束し、構成部品の円形パターンで増やす。
- 座標系は X = 前、Y = 上、Z = 右舷。

## 6. 共締め穴

相手部品とボルトで共締めする穴は、トップアセンブリの穴フィーチャとして開け、加工部品へ反映する。
位置を変えるとつながる部品すべてに効く。

- 対象は加工部品だけ。購入品は自身の図面どおりの穴を部品側に持たせ、位置は同じ変数で決める。
- 同じ部品ファイルを複数個使っているときは 1 個だけを対象にする。全部を対象にすると同じ穴が二重に反映される。
- 貫通穴も深さで指示する。作成後に貫通へ変更すると、反映が作り直されて部品側に重複が残る。
- 反映された穴は部品側で「穴 1 個＝フィーチャ 1 個」になり、位置スケッチはアセンブリを参照する（部品単体では未定義に見える）。

## 7. 購入品

購入品は外形の代用モデルではなく、メーカーが配布している 3D データを取り込んで使う。干渉確認の精度のため。

- 取り込み元は `cad_source/vendor/` に置き、入手元を `cad_source/README.md` に記録する。
- 配布データは原点も向きもまちまちなので、「ボディの移動/コピー」で向きをそろえて `cad/00_既製品/` の部品にする。
  ソリッドにならず面のまま入った形状も一緒に動かす。
- データが無い品目は寸法図から作図し、プロパティの備考にその旨を書く。
- ねじ・ナット・座金などの MISUMI 品は、MISUMI RAPiD Design（SOLIDWORKS アドイン）で型番を指定して入れる。
  自作の外形モデルで代用しない。

## 8. 生成の速さ

速く終わらせる段取りは `swkit.Project.build` に入っていて、設計ごとのコードには書かない。

- 作り方と設計変数が前回と同じ部品は、保存済みのファイルを使い回す。
- 共締め穴の対象になるユニットだけを先にトップアセンブリへ載せて穴を開け、残りのユニットはそのあとで載せる。
- 穴を開けている間と部品を作っている間は、画面とフィーチャツリーの更新を止める。
- SOLIDWORKS へ命令を送るスクリプトは同時に 2 本走らせない。

## 9. ファイル配置

```text
CAD/
|-- 00_既製品/                 購入品（品番をファイル名にする）
`-- 01_<製品名>/
    |-- <製品>.SLDASM           トップアセンブリ（レイアウトスケッチを持つ）
    `-- NN_<ユニット名>/         サブアセンブリと加工部品
```
